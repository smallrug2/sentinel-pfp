Gradient Letter Avatar Maker (sentinel_pfp.py)

WHAT IT DOES:
Renders 512px profile pictures: dark background, gradient ring badge, letter emblem, 3 color themes.

REQUIREMENTS:
Python 3.8+ and Pillow: pip install Pillow

HOW TO RUN:
python sentinel_pfp.py --help
python sentinel_pfp.py --letter S --out pfp.png

PLATFORM:
Windows + Linux + Mac: yes.
